# Shared Course Reference Materials

This directory stores cross-cutting textbooks, monographs, foundational papers, and reference notes common across both Volume I (Lectures) and Volume II (Laboratories).

## 1. General Course Textbooks (`books/`)
- **Sebastian Raschka (2024)**: *Build a Large Language Model (from Scratch)*, Manning Publications.
  - File: `Build a Large Language Model from scratch (Sebastian Raschka).epub`
  - Covers: Tokenization, embedding tables as linear layers, Multi-Head Attention, GPT pretraining, fine-tuning.
- **Welch (2024)**: *The Illustrated Guide to AI*.
  - File: `2024-welch-illustrated-guide-to-ai.pdf`
  - Covers: Visual deep learning mechanics, backpropagation, and foundation model architectures.
- **Xiao & Zhu (2025)**: *Foundations of Large Language Models*.
  - File: `2025-xiao-zhu-foundations-of-large-language-models.pdf`
  - Covers: Scaling laws, theoretical bounds, pre-training dynamics.

## 2. Shared Foundational Papers (`papers/`)
- Shannon, C. E. (1948). *A Mathematical Theory of Communication*.
- Rumelhart, D. E., Hinton, G. E., & Williams, R. J. (1986). *Learning representations by back-propagating errors*.
- Bengio, Y., et al. (2003). *A Neural Probabilistic Language Model*.
- Vaswani, A., et al. (2017). *Attention Is All You Need*.
- Radford, A., et al. (2019). *Language Models are Unsupervised Multitask Learners* (GPT-2).
- Hoffmann, J., et al. (2022). *Training Compute-Optimal Large Language Models* (Chinchilla).

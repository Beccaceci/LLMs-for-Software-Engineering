\chapter{Transformer Variants and Decoding}
\label{ch:transformer_variants}

Chapter~\ref{ch:transformer_architecture} established the foundational mathematics of the canonical Transformer, detailing how multi-head self-attention, cross-attention, and position-wise feed-forward networks overcome the sequential bottlenecks of recurrent architectures. While that framework was originally formulated as a dual-stack encoder-decoder for bilingual machine translation, subsequent deep learning research recognized that the encoder and decoder perform distinct representational functions that can be decoupled and specialized for different NLP tasks.

This structural divergence produced three principal architectural paradigms: unified encoder-decoder models conditioned on arbitrary task prefixes, encoder-only models leveraging unconstrained bidirectional context for sequence comprehension, and decoder-only models employing causal autoregression for open-ended generative synthesis. Concurrently, generating coherent natural text from autoregressive distributions revealed fundamental limitations in classical maximization decoding algorithms, necessitating the development of probabilistic truncation heuristics.

This chapter provides an exhaustive theoretical and empirical examination of Transformer architectural specializations and decoding mechanics. We begin by analyzing the multi-task text-to-text paradigm embodied by T5, dissecting its prefix-conditioning mechanism and dual-stack computational bottlenecks. We then deconstruct encoder-only representations through BERT, formalizing its tripartite input embedding structure, self-supervised pre-training objectives, emergent attention head specializations, and downstream task adaptation heads. Next, we formalize the decoder-only causal architecture, deriving its exact autoregressive probability factorization, causal masking mechanics, and computational rationale for modern large language models. Finally, we dissect the decoding spectrum, formulating deterministic and stochastic sampling strategies and evaluating their failure modes and empirical behaviors through rigorous mathematical formulations and controlled generation benchmarks.


\section{Encoder-Decoder Models}
\label{sec:encoder_decoder_models}

The canonical Transformer proposed by Vaswani et al.~\cite{vaswani2017} was engineered specifically for sequence-to-sequence machine translation, mapping an input sequence in a source language to a corresponding sequence in a target language. In that original paradigm, model weights were strictly specialized for an isolated task and language pair. The text-to-text transfer framework introduced by Raffel et al.~\cite{raffel2020t5} fundamentally reimagined this dual-stack topology, proving that a single shared parameterization could execute heterogeneous natural language processing tasks by unifying their input-output formats into a shared string-to-string interface.


\subsection{The unified text-to-text framework and T5}
\label{subsec:t5_text_to_text}

Prior to the introduction of unified text-to-text architectures, empirical natural language processing relied on fragmented task-specific design conventions. Researchers typically affixed specialized classification layers atop an encoder for sentiment analysis, token-level linear classifiers for named entity recognition, regression heads for semantic textual similarity, or specialized sequence-to-sequence decoders for summarization and translation. Each downstream objective demanded a bespoke loss formulation, architectural head modification, and dedicated optimization schedule.

The Text-to-Text Transfer Transformer (T5) introduced by Raffel et al.~\cite{raffel2020t5} resolved this fragmentation by reframing every natural language objective as a text generation problem. Formally, let $\mathcal{V}^*$ denote the set of all arbitrary-length token sequences formed from vocabulary $\mathcal{V}$. Regardless of whether the underlying target is continuous regression, categorical classification, span extraction, or sequence translation, both the model input $\mathbf{x} \in \mathcal{V}^*$ and output $\mathbf{y} \in \mathcal{V}^*$ are represented exclusively as plain text strings:
\begin{equation}
f_{\boldsymbol{\theta}}: \mathcal{V}^* \to \mathcal{V}^*, \quad \mathbf{y} = f_{\boldsymbol{\theta}}(\mathbf{x}).
\label{eq:t5_text_to_text_mapping}
\end{equation}

To enable a single invariant set of network parameters $\boldsymbol{\theta}$ to distinguish between competing functional objectives, T5 introduces \emph{task-specific conditioning prefixes}. The user or training pipeline prepends a discrete textual indicator to the source sequence specifying the operational transformation desired. Figure~\ref{fig:t5_architecture} illustrates this unified conditioning paradigm across four disparate NLP tasks.

The mathematical elegance of this formulation lies in the universal applicability of the standard autoregressive maximum-likelihood objective. For any dataset $\mathcal{D} = \{(\mathbf{x}^{(m)}, \mathbf{y}^{(m)})\}_{m=1}^M$, the network is trained using token-level teacher-forced cross-entropy:
\begin{equation}
\mathcal{L}_{\text{seq2seq}}(\boldsymbol{\theta}) = -\sum_{m=1}^M \sum_{t=1}^{T_m} \log P\left(y_t^{(m)} \mid y_{<t}^{(m)}, \mathbf{x}^{(m)}; \boldsymbol{\theta}\right),
\label{eq:t5_seq2seq_loss}
\end{equation}
where $y_t^{(m)}$ represents the $t$-th target token of sequence $m$ and $T_m$ is its length. Continuous regression tasks such as STS-B are handled by requiring the model to emit decimal digit tokens (e.g., \texttt{"3.8"}), which are parsed back to floating-point values at inference. Binary classification tasks emit string literals (\texttt{"acceptable"} or \texttt{"not acceptable"}).

Crucially, as emphasized in course lectures, this prefix-conditioning paradigm must not be confused with modern instruction tuning. In T5, the model does not possess open-ended natural language intent comprehension. The prefix strings are rigid, memorized syntactic conditioning triggers encountered during multi-task pre-training. If an unobserved or perturbed phrasing is supplied (for example, substituting \texttt{"can you translate from English to German:"} in place of \texttt{"translate English to German:"}), the conditioning signal degrades significantly because the underlying weights merely map memorized prompt templates to target output manifolds.


\subsection{Architectural modifications and pre-training in T5}
\label{subsec:t5_mechanics}

Beyond its operational text-to-text unification, T5 introduced key architectural deviations from the original 2017 Transformer specification to improve optimization stability and representation quality.

First, T5 dispenses with fixed absolute sinusoidal positional encodings $\mathbf{p}_i \in \mathbb{R}^{d_{\text{model}}}$. Instead, it adopts a parameterized \emph{relative position bias}. Under this formulation, the scalar pre-softmax attention score between query token $i$ and key token $j$ is augmented by a learnable scalar offset $b_{i,j}$:
\begin{equation}
A_{i,j} = \frac{\mathbf{q}_i^\top \mathbf{k}_j}{\sqrt{d_k}} + b_{i,j},
\label{eq:t5_relative_bias}
\end{equation}
where $b_{i,j}$ depends strictly on the relative displacement $(i - j)$. To bound the parameter footprint while retaining long-range sensitivity, displacements are mapped into discrete logarithmic buckets. Small relative distances ($|i - j| < 8$) receive exact dedicated bias parameters, whereas larger offsets are compressed logarithmically up to a maximum context window. This structure enforces translation invariance along sequence positions and enables extrapolation across varying sequence lengths.

Second, T5 simplifies the normalization topology by utilizing a modified root-mean-square normalization where the activation vector $\mathbf{x} \in \mathbb{R}^{d_{\text{model}}}$ is normalized strictly by its second moment without subtracting the mean:
\begin{equation}
\text{RMSNorm}(\mathbf{x}) = \frac{\mathbf{x}}{\sqrt{\frac{1}{d_{\text{model}}} \sum_{k=1}^{d_{\text{model}}} x_k^2 + \epsilon}} \odot \boldsymbol{\gamma},
\label{eq:t5_rmsnorm}
\end{equation}
where $\boldsymbol{\gamma} \in \mathbb{R}^{d_{\text{model}}}$ is a learned scaling vector and $\epsilon > 0$ guarantees numerical stability. Normalization is placed on the input paths of each sub-block (\emph{Pre-LN}), stabilizing backpropagation gradients through residual connections.

Third, for self-supervised pre-training over the Colossal Clean Crawled Corpus (C4), T5 introduced a compute-efficient \emph{span corruption} objective. Rather than masking individual isolated tokens, contiguous spans of text (averaging 3 tokens in length, totaling $15\%$ of the sequence) are replaced by unique sentinel tokens $\langle\text{extra\_id\_0}\rangle, \langle\text{extra\_id\_1}\rangle, \dots$. The target sequence $\mathbf{y}$ consists exclusively of these sentinel tokens followed by their excised original text. By omitting uncorrupted tokens from the decoder targets, T5 drastically reduces the decoder sequence length during pre-training, yielding substantial computational savings over standard sequence reconstruction.


\subsection{Trade-offs and computational bottlenecks of dual-stack models}
\label{subsec:tradeoffs_enc_dec}

Despite the elegance of the text-to-text abstraction, full encoder-decoder architectures impose structural and computational overheads that ultimately motivated researchers to explore single-stack variants.

\begin{enumerate}
    \item \textbf{Parameter Redundancy in Separate Stacks}: An encoder-decoder network maintains two complete Transformer stacks. For an $L$-layer architecture with hidden dimension $d_{\text{model}}$ and feed-forward dimension $d_{\text{ff}}$, the model instantiates $L$ bidirectional encoder blocks and $L$ causal decoder blocks. Furthermore, every decoder layer must maintain an additional multi-head cross-attention mechanism with parameter projection matrices $\mathbf{W}^Q_{\text{cross}}, \mathbf{W}^K_{\text{cross}}, \mathbf{W}^V_{\text{cross}} \in \mathbb{R}^{d_{\text{model}} \times d_{\text{model}}}$ and $\mathbf{W}^O_{\text{cross}} \in \mathbb{R}^{d_{\text{model}} \times d_{\text{model}}}$. When evaluated against a single-stack architecture of equivalent total parameter volume, parameter capacity is split between encoding and decoding stages.
    
    \item \textbf{Cross-Attention Memory and Latency Footprint}: In the decoding phase, generating each output token requires computing attention across the entire encoded representation. For an input sequence of length $S$ and an output sequence of length $T$, cross-attention requires materializing and storing key-value tensors $\mathbf{K}_{\text{cross}}, \mathbf{V}_{\text{cross}} \in \mathbb{R}^{S \times d_k}$ across all heads and layers. The cumulative cross-attention computational complexity scales as $\mathcal{O}(L \cdot S \cdot T \cdot d_{\text{model}})$. In latency-critical deployment scenarios, repeatedly attending over static encoder states creates high memory bandwidth demands.
    
    \item \textbf{Asymmetric Computational Allocation}: Natural language tasks exhibit marked structural asymmetry. In pure comprehension problems (e.g., text categorization, document retrieval, grammatical acceptability), generating an autoregressive sequence of tokens via a decoder stack is strictly superfluous; a direct pooling of the encoded states provides sufficient representation. Conversely, in open-ended generative tasks (e.g., creative writing, dialogue, code synthesis), there is no distinct "source" sequence to encode; the prompt is merely the initial conditioning segment of a single unified sequence.
\end{enumerate}

These structural trade-offs led to an architectural fork: removing the autoregressive decoder produced bidirectional \emph{encoder-only} representations, whereas removing the encoder and cross-attention produced causal \emph{decoder-only} generative architectures.


\section{Encoder-Only Models}
\label{sec:encoder_only_bert}

When an application demands deep semantic understanding, entity tagging, syntactic parsing, or document classification rather than open-ended text synthesis, the autoregressive decoder constitutes unnecessary computational overhead. By excising the decoder stack entirely and eliminating the causal triangular attention mask, the model gains unconstrained bidirectional context: every token at every layer attends simultaneously to all prior, concurrent, and subsequent tokens.

The archetypal implementation of this paradigm is BERT (\emph{Bidirectional Encoder Representations from Transformers}), introduced by Devlin et al.~\cite{devlin2019}. Figure~\ref{fig:encoder_only_bert} depicts the architectural topology of an encoder-only model.

\label{subsec:bert_input_representation}

\label{fig:bert_input_encoding}

Formally, for position $i$ in a packed sequence, the input embedding vector $\mathbf{E}_{\text{in}}(i) \in \mathbb{R}^{d_{\text{model}}}$ is defined by:
\begin{equation}
\mathbf{E}_{\text{in}}(i) = \mathbf{E}_{\text{token}}(t_i) + \mathbf{E}_{\text{segment}}(s_i) + \mathbf{E}_{\text{pos}}(i),
\label{eq:bert_input_embedding_sum}
\end{equation}
where:
\begin{enumerate}
    \item $\mathbf{E}_{\text{token}}(t_i) \in \mathbb{R}^{d_{\text{model}}}$ maps subword tokens $t_i$ derived via WordPiece tokenization ($|\mathcal{V}| \approx 30,522$) into continuous embeddings.
    \item $\mathbf{E}_{\text{segment}}(s_i) \in \{\mathbf{E}_A, \mathbf{E}_B\}$ denotes a learned segment embedding assigned to distinguish the first sentence (Sentence $A$) from the contiguous or paired second sentence (Sentence $B$).
    \item $\mathbf{E}_{\text{pos}}(i) \in \mathbb{R}^{d_{\text{model}}}$ represents a learned absolute positional embedding index up to a context length of 512 tokens.
\end{enumerate}

To structure multi-sentence reasoning and facilitate task classification, BERT introduces two essential delimiter tokens:
\begin{itemize}
    \item \texttt{[CLS]} (\emph{Classification}): Always prepended as the zeroth token ($t_0$) of every sequence. Because self-attention is unconstrained, the hidden state $\mathbf{h}_{[\text{CLS}]} \in \mathbb{R}^{d_{\text{model}}}$ accumulates contextual information across all tokens, functioning as an aggregate sequence representation for classification heads.
    \item \texttt{[SEP]} (\emph{Separator}): Inserted between Sentence $A$ and Sentence $B$, and appended at the final position of the sequence. It acts as an unambiguous structural barrier between distinct semantic segments.
\end{itemize}


\subsection{Pre-training task 1: Masked Language Model (MLM)}
\label{subsec:bert_masked_lm}

In an unconstrained bidirectional encoder, standard autoregressive next-token prediction is mathematically degenerate: since token $i$ directly attends to token $i+1$, predicting $x_{i+1}$ would trivially reduce to reading the unmasked future token. To train a deep bidirectional representation without informational leakage, Devlin et al.~\cite{devlin2019} designed the \emph{Masked Language Model} (MLM) objective.

Figure~\ref{fig:bert_masked_lm} shows the MLM execution flow. In each training sequence, approximately $15\%$ of all WordPiece tokens are selected uniformly at random for prediction. However, naively replacing every chosen token with a fixed \texttt{[MASK]} token introduces a severe \emph{pre-training/fine-tuning discrepancy}: the \texttt{[MASK]} token never appears during downstream fine-tuning.

To mitigate this distribution shift, Devlin et al. introduced an $80/10/10$ corruption schedule for the selected $15\%$ candidate positions:
\begin{enumerate}
    \item \textbf{$80\%$ of the time}: The token is replaced with the special symbol \texttt{[MASK]}.
    \item \textbf{$10\%$ of the time}: The token is replaced with a randomly sampled token from the vocabulary $\mathcal{V}$. This induces contextual vigilance: because any token might be an injected error, the network cannot simply learn that non-\texttt{[MASK]} tokens are always correct.
    \item \textbf{$10\%$ of the time}: The token is left unaltered. This forces the encoder to maintain a faithful representation of the true observed token.
\end{enumerate}

Formally, let $\mathcal{M}$ denote the set of corrupted token indices. For each index $i \in \mathcal{M}$, the final contextual hidden vector $\mathbf{h}_i \in \mathbb{R}^{d_{\text{model}}}$ is passed through a shared linear projection $\mathbf{W}_{\text{mlm}} \in \mathbb{R}^{|\mathcal{V}| \times d_{\text{model}}}$ followed by a softmax:
\begin{equation}
P(x_i = v \mid \mathbf{h}_i) = \frac{\exp(\mathbf{w}_v^\top \mathbf{h}_i + b_v)}{\sum_{v' \in \mathcal{V}} \exp(\mathbf{w}_{v'}^\top \mathbf{h}_i + b_{v'})}.
\label{eq:bert_mlm_prediction_prob}
\end{equation}
The MLM loss is computed strictly over the corrupted positions:
\begin{equation}
\mathcal{L}_{\text{MLM}}(\boldsymbol{\theta}) = -\sum_{i \in \mathcal{M}} \log P(x_i = t_i^* \mid \mathbf{h}_i; \boldsymbol{\theta}),
\label{eq:bert_mlm_cross_entropy_loss}
\end{equation}
where $t_i^*$ is the ground-truth token identity before corruption.


\subsection{Pre-training task 2: Next Sentence Prediction (NSP)}
\label{subsec:bert_nsp}

While MLM develops fine-grained token-level contextual representations, many downstream NLP applications (such as Natural Language Inference and Question Answering) require modeling relational semantics between pairs of sentences. To explicitly train sentence relationship modeling, BERT incorporates the \emph{Next Sentence Prediction} (NSP) binary classification objective.

Figure~\ref{fig:bert_nsp} illustrates the NSP formulation. Input sequences are assembled by concatenating sentence pairs:
\begin{equation}
\mathbf{x} = (\texttt{[CLS]}, a_1, \dots, a_{|A|}, \texttt{[SEP]}, b_1, \dots, b_{|B|}, \texttt{[SEP]}).
\end{equation}
Training instances are sampled according to a balanced binary protocol:
\begin{itemize}
    \item \textbf{$50\%$ of instances (Positive Class: \texttt{IsNext})}: Sentence $B$ is the actual contiguous sentence following Sentence $A$ in the source corpus.
    \item \textbf{$50\%$ of instances (Negative Class: \texttt{NotNext})}: Sentence $B$ is a random sentence sampled independently from another document in the corpus.
\end{itemize}

At the model output, the hidden state corresponding to the first token, $\mathbf{h}_{[\text{CLS}]} \in \mathbb{R}^{d_{\text{model}}}$, is mapped through a non-linear pooler layer with parameter matrix $\mathbf{W}_{\text{pool}} \in \mathbb{R}^{d_{\text{model}} \times d_{\text{model}}}$:
\begin{equation}
\mathbf{c} = \tanh(\mathbf{W}_{\text{pool}} \mathbf{h}_{[\text{CLS}]} + \mathbf{b}_{\text{pool}}).
\label{eq:bert_pooled_cls_representation}
\end{equation}
A binary classification projection $\mathbf{W}_{\text{NSP}} \in \mathbb{R}^{2 \times d_{\text{model}}}$ computes the class probabilities:
\begin{equation}
P(\text{IsNext} \mid \mathbf{c}) = \frac{\exp(\mathbf{w}_{\text{next}}^\top \mathbf{c})}{\exp(\mathbf{w}_{\text{next}}^\top \mathbf{c}) + \exp(\mathbf{w}_{\text{not}}^\top \mathbf{c})}.
\label{eq:bert_nsp_probability}
\end{equation}

The cumulative pre-training loss combines the MLM and NSP objectives over every mini-batch:
\begin{equation}
\mathcal{L}_{\text{total}}(\boldsymbol{\theta}) = \mathcal{L}_{\text{MLM}}(\boldsymbol{\theta}) + \mathcal{L}_{\text{NSP}}(\boldsymbol{\theta}).
\label{eq:bert_total_pretraining_objective}
\end{equation}


\subsection{Attention map anatomy and emergent linguistic structures}
\label{subsec:bert_attention_map_anatomy}

An instructive insight from the BERT architecture is that multi-head bidirectional self-attention naturally develops specialized linguistic capabilities without explicit syntactic supervision. In $\text{BERT}_{\text{BASE}}$, the model instantiates $L=12$ layers with $H=12$ attention heads per layer, computing:
\begin{equation}
N_{\text{maps}} = 12 \times 12 = 144
\label{eq:bert_total_attention_heads}
\end{equation}
distinct attention matrices per sequence. For a sequence of length $N$, each attention map is an $N \times N$ matrix $\mathbf{A} \in [0, 1]^{N \times N}$ where entry $A_{i,j}$ indicates the attention weight that token $i$ assigns to token $j$.

In course lectures, the internal mechanics of these 144 attention heads are analyzed using the running sentence:
\begin{equation*}
\texttt{"[CLS] The dog ate the food because it was hungry [SEP]"}
\end{equation*}
comprising $N=11$ tokens. Empirical probing of these attention maps, formalizing studies by Clark et al.~\cite{clark2019what} and Michel et al.~\cite{michel2019sixteen}, reveals two striking emergent phenomena:

            \item \textbf{Verb-Object Dependency}: Token \texttt{"ate"} directs strong attention to direct object \texttt{"food"}.

        \end{itemize}

            \item \textbf{Delimiter Collapse}: In deeper layers (Layers 9--12), multiple heads assign $\ge 80\%$ of their attention mass directly to \texttt{[SEP]} and \texttt{[CLS]}.
            \item \textbf{Computational "No-Op"}: As proven by Michel et al.~\cite{michel2019sixteen}, when a specialized head detects no applicable linguistic relationship for a query token, it parks its softmax probability mass on delimiter tokens.
            \item \textbf{Null Gradient Channel}: Delimiters serve as neutral registers, preventing erroneous modification of contextual features.
        \end{itemize}
    };
\end{tikzpicture}
\caption{Emergent linguistic specialization and delimiter behavior across BERT attention heads \cite{clark2019what, michel2019sixteen}. Middle layers resolve syntactic dependencies and coreferences, while deeper layers utilize delimiter tokens as computational no-op registers.}
\label{fig:bert_attention_maps_specialization}

\begin{enumerate}
    \item \textbf{Syntactic and Coreference Specialization}: In middle layers (Layers 5 through 8), individual attention heads function as soft syntactic parsers. For example, when resolving the pronoun \texttt{"it"}, specific heads route their primary attention mass ($A_{i,j} > 0.80$) back to the antecedent noun phrase \texttt{"dog"}. Because the self-attention formula is unconstrained, token representations dynamically absorb semantic properties from their syntactic referents. Similarly, verbs attend directly to their objects (e.g., \texttt{"ate"} attends strongly to \texttt{"food"}).
    
    \item \textbf{Delimiter Registers as Computational "No-Ops"}: In higher layers (Layers 9 through 12), an intriguing behavior emerges: an overwhelming fraction of query tokens assign the vast majority of their attention probability to delimiter tokens, predominantly \texttt{[SEP]} and \texttt{[CLS]}. Clark et al.~\cite{clark2019what} established that delimiter tokens act as \emph{computational no-op registers}. Softmax requires rows of the attention matrix to sum strictly to 1:
    \begin{equation}
    \sum_{j=1}^N A_{i,j} = 1.
    \label{eq:softmax_row_sum_one}
    \end{equation}
    If a specialized head (e.g., a preposition detector) evaluates a query token that has no relevant dependency in the sentence, it cannot emit a zero vector from softmax. To prevent injecting spurious semantic information into the residual stream, the head routes its attention mass to \texttt{[SEP]}, whose representation functions as a neutral null register.
\end{enumerate}


\subsection{Downstream task adaptation}
\label{subsec:bert_downstream_finetuning}

To adapt the pre-trained encoder to specific downstream tasks, the pre-training MLM and NSP projection layers are discarded and replaced with lightweight, task-specific output layers. The entire network is then fine-tuned end-to-end:

\begin{enumerate}
    \item \textbf{Sentence-Level Classification (e.g., SST-2, MNLI)}: The classification head maps the aggregate representation $\mathbf{h}_{[\text{CLS}]}$ through a projection matrix $\mathbf{W}_{\text{cls}} \in \mathbb{R}^{K \times d_{\text{model}}}$:
    \begin{equation}
    \hat{\mathbf{y}} = \text{Softmax}(\mathbf{W}_{\text{cls}} \mathbf{h}_{[\text{CLS}]} + \mathbf{b}_{\text{cls}}).
    \label{eq:bert_finetune_seq_classification}
    \end{equation}
    
    \item \textbf{Token-Level Tagging (e.g., NER, POS Tagging)}: Each token position $i$ passes its hidden vector $\mathbf{h}_i \in \mathbb{R}^{d_{\text{model}}}$ to a shared linear projection $\mathbf{W}_{\text{tok}} \in \mathbb{R}^{C \times d_{\text{model}}}$:
    \begin{equation}
    \hat{\mathbf{y}}_i = \text{Softmax}(\mathbf{W}_{\text{tok}} \mathbf{h}_i + \mathbf{b}_{\text{tok}}).
    \label{eq:bert_finetune_token_classification}
    \end{equation}
    
    \item \textbf{Extractive Question Answering (e.g., SQuAD)}: The model learns two parameter vectors, $\mathbf{s}, \mathbf{e} \in \mathbb{R}^{d_{\text{model}}}$, corresponding to span start and span end predictors. The probability that token $i$ marks the start of the answer span is given by:
    \begin{equation}
    P_{\text{start}}(i) = \frac{\exp(\mathbf{s}^\top \mathbf{h}_i)}{\sum_{j=1}^N \exp(\mathbf{s}^\top \mathbf{h}_j)},
    \label{eq:bert_squad_start_prob}
    \end{equation}
    with an identical formulation parameterized by $\mathbf{e}$ for the span terminus.
\end{enumerate}


\section{Decoder-Only Models}
\label{sec:decoder_only_models}

While bidirectional encoders excel at discriminative understanding and sequence labeling, they cannot naturally synthesize open-ended natural text. Generating a sequence autoregressively with an unconstrained bidirectional model requires repeatedly re-encoding candidate completions with iterative masking heuristics, which is computationally inefficient.

The causal \emph{decoder-only} architecture resolves this limitation by discarding the encoder stack and cross-attention blocks entirely. The prompt sequence is supplied directly as the initial prefix of the decoder stack, and generation proceeds sequentially via strictly causal self-attention.


\subsection{Causal autoregressive formulation and architecture topology}
\label{subsec:causal_autoregression_topology}

In a decoder-only architecture, the joint probability of an arbitrary sequence $\mathbf{x} = (x_1, x_2, \dots, x_N)$ over vocabulary $\mathcal{V}$ is decomposed via the exact probability chain rule without Markov independence assumptions:
\begin{equation}
P(\mathbf{x}) = \prod_{i=1}^N P(x_i \mid x_1, x_2, \dots, x_{i-1}) = \prod_{i=1}^N P(x_i \mid \mathbf{x}_{<i}).
\label{eq:autoregressive_chain_rule}
\end{equation}
Taking the negative logarithm yields the canonical autoregressive next-token prediction objective:
\begin{equation}
\mathcal{L}_{\text{AR}}(\boldsymbol{\theta}) = -\sum_{i=1}^N \log P(x_i \mid \mathbf{x}_{<i}; \boldsymbol{\theta}).
\label{eq:clm_objective_formal}
\end{equation}

To compute representations for all positions $i \in \{1, \dots, N\}$ in parallel during training without violating the causal factorization in Equation~\eqref{eq:autoregressive_chain_rule}, the architecture enforces strict temporal masking within every self-attention layer. Let $\mathbf{Q}, \mathbf{K} \in \mathbb{R}^{N \times d_k}$ denote the query and key projection matrices for a given attention head. The pre-softmax logit matrix is augmented by an additive causal mask $\mathbf{M} \in \{0, -\infty\}^{N \times N}$:
\begin{equation}
\mathbf{A} = \text{Softmax}\left(\frac{\mathbf{Q}\mathbf{K}^\top}{\sqrt{d_k}} + \mathbf{M}\right),
\label{eq:causal_masked_attention}
\end{equation}
where the mask matrix $\mathbf{M}$ is defined by:
\begin{equation}
M_{i,j} = \begin{cases}
0 & \text{if } j \le i, \\
-\infty & \text{if } j > i.
\end{cases}
\label{eq:causal_mask_matrix}
\end{equation}

Because $\exp(-\infty) = 0$, attention weights for all future positions $j > i$ are zero. Thus, the contextual hidden state $\mathbf{h}_i \in \mathbb{R}^{d_{\text{model}}}$ at position $i$ is an exact deterministic function of the prefix $\mathbf{x}_{\le i}$ and remains independent of subsequent tokens $x_{j > i}$.


\subsection{Architectural streamlining: eliminating encoder and cross-attention}
\label{subsec:decoder_streamlining}

Relative to the canonical Transformer, the decoder-only architecture simplifies the processing pipeline:

\begin{enumerate}
    \item \textbf{Elimination of the Encoder Stack}: Rather than projecting source text into an intermediate representation space via an independent encoder, the conditioning prompt is simply ingested as the initial prefix of the decoder sequence.
    \item \textbf{Excise of Cross-Attention Sub-Layers}: Because there is no external encoder state, each decoder block contains only two core components: a causal masked multi-head self-attention layer and a position-wise feed-forward network. This reduces the number of matrix projections per layer from eight ($\mathbf{W}^Q, \mathbf{W}^K, \mathbf{W}^V, \mathbf{W}^O$ for self-attention; $\mathbf{W}^Q, \mathbf{W}^K, \mathbf{W}^V, \mathbf{W}^O$ for cross-attention) to four.
    \item \textbf{Training Parallelism via Teacher Forcing}: Although inference is necessarily sequential (generating one token at a time), training remains fully parallel. The ground-truth sequence is supplied as input, and causal triangular masking ensures that predictions for all positions are computed in a single forward pass under the teacher-forcing paradigm.
\end{enumerate}


\subsection{Convergence on the decoder-only paradigm}
\label{subsec:decoder_only_dominance}

The NLP research community progressively standardized on decoder-only architectures for large-scale foundation models. This convergence was driven by fundamental computational and operational advantages:

\begin{enumerate}
    \item \textbf{Homogeneous Key-Value Cache Memory Layout}: In an encoder-decoder architecture, autoregressive generation requires maintaining two separate key-value caches: a static encoder cache $\mathbf{K}_{\text{enc}}, \mathbf{V}_{\text{enc}} \in \mathbb{R}^{S \times d_k}$ and a growing decoder cache $\mathbf{K}_{\text{dec}}, \mathbf{V}_{\text{dec}} \in \mathbb{R}^{t \times d_k}$. Managing heterogeneous memory buffers across distributed accelerator clusters complicates tensor-parallel and pipeline-parallel execution. In contrast, decoder-only architectures maintain a single, append-only key-value cache buffer.
    
    \item \textbf{Universal In-Context Sequence Interface}: By unifying input context and output completions into a single autoregressive sequence, decoder-only models natively support few-shot prompting, multi-turn dialogue, and chain-of-thought reasoning without requiring specialized architectural modifications or task-specific fine-tuning.
\end{enumerate}

The empirical scaling laws, pre-training corpus curation strategies, and historical milestones (from GPT-1 and GPT-2 to massive modern parameter regimes) that established this paradigm's dominance are examined comprehensively in Chapter~\ref{ch:scaling_laws_pretraining}.


\section{Decoding and Sampling Strategies}
\label{sec:decoding_and_sampling}

Regardless of whether an architecture employs an encoder-decoder or decoder-only topology, generating text requires converting continuous output vectors into discrete token sequences. At generation step $t$, the final hidden state $\mathbf{h}_t \in \mathbb{R}^{d_{\text{model}}}$ is projected onto vocabulary $\mathcal{V}$ via the unembedding matrix $\mathbf{W}_U \in \mathbb{R}^{|\mathcal{V}| \times d_{\text{model}}}$ to yield raw logits $\mathbf{z}_t \in \mathbb{R}^{|\mathcal{V}|}$:
\begin{equation}
\mathbf{z}_t = \mathbf{W}_U \mathbf{h}_t + \mathbf{b}_U.
\label{eq:unembedding_projection_formal}
\end{equation}
Applying the softmax operator produces a categorical probability distribution over all known tokens:
\begin{equation}
P(x_t = v \mid \mathbf{x}_{<t}) = \frac{\exp(z_{t,v})}{\sum_{j=1}^{|\mathcal{V}|} \exp(z_{t,j})}, \quad \forall v \in \{1, \dots, |\mathcal{V}|\}.
\label{eq:unembedding_softmax_distribution}
\end{equation}

Selecting discrete tokens $\hat{x}_t$ from this distribution is governed by the \emph{decoding strategy}. As established in course lectures, selecting tokens naively via probability maximization leads to degenerative failure modes. This section formalizes the complete taxonomy of deterministic and stochastic decoding algorithms, illustrated through the running course generation benchmark based on the Sherlock Holmes prompt from Slides~98--112.


\subsection{The decoding dilemma: maximization versus degeneration}
\label{subsec:decoding_dilemma}

A natural formulation of text generation is maximum a posteriori (MAP) decoding, seeking the sequence $\mathbf{y}^* = (\hat{x}_1, \dots, \hat{x}_T)$ that maximizes the joint conditional likelihood:
\begin{equation}
\mathbf{y}^* = \arg\max_{\mathbf{y}} P(\mathbf{y} \mid \mathbf{x}_{\text{prompt}}) = \arg\max_{\mathbf{y}} \sum_{t=1}^T \log P(x_t \mid \mathbf{x}_{<t}).
\label{eq:map_decoding_objective}
\end{equation}

Exact maximization over the combinatorial space $\mathcal{V}^T$ requires evaluating $|\mathcal{V}|^T$ trajectories, which is computationally intractable for modern vocabularies ($|\mathcal{V}| \ge 32,000$, $T \ge 100$). However, even when approximated, pure likelihood maximization exhibits severe failure modes in open-ended natural text generation. As demonstrated by Holtzman et al.~\cite{holtzman2020}, human language does not maximize probability at every step. Maximization decoding frequently causes \emph{degeneration}, where the model becomes trapped in repetitive loops or emits generic, uninformative phrases.


\subsection{Deterministic decoding: greedy search and beam search}
\label{subsec:deterministic_decoding}

Deterministic decoding strategies map a logit distribution to a unique, reproducible output sequence without stochastic sampling.

\paragraph{Greedy Decoding}
Greedy search selects the single token with the highest predicted probability at each step:
\begin{equation}
\hat{x}_t = \arg\max_{v \in \mathcal{V}} P(x_t = v \mid \mathbf{x}_{<t}) = \arg\max_{v \in \mathcal{V}} z_{t,v}.
\label{eq:greedy_selection}
\end{equation}

While computationally minimal ($\mathcal{O}(1)$ selection cost), greedy decoding suffers from two fatal deficiencies:
\begin{itemize}
    \item \textbf{Search Myopia}: Greedy decoding cannot look beyond the immediate token. Selecting an apparently optimal token at step $t$ can steer the network into a low-probability manifold at step $t+1$, missing globally higher-likelihood sequences that began with a lower-probability initial token.
    \item \textbf{Cyclic Repetition Loops}: In open-ended generation, greedy selection reliably causes infinite repetitive loops.
\end{itemize}

This pathology is highlighted in Slide~100 of the course materials. When conditioning GPT-2 on the Arthur Conan Doyle prompt:
\begin{quote}
\emph{"I had called upon my friend, Mr. Sherlock Holmes, one day in the autumn of last year and found him in deep conversation with a very stout, florid-faced, elderly gentleman with fiery red hair. With an apology for my intrusion, I was about to withdraw when Holmes pulled me abruptly into the room and closed the door behind me."}
\end{quote}
greedy decoding produces the following degenerate continuation:
\begin{quote}
\texttt{"I am sorry, Mr. Holmes," I said, "but I am not going to tell you what I have seen. I am afraid I have not seen you in a long time. I am afraid I have not seen you in a long time. I am afraid I have not seen you in a long time. I am afraid I have not seen you in a long time. I am afraid I have not seen..."}
\end{quote}

Once a token sequence repeats, the self-attention mechanism reinforces the historical pattern, driving the model into an inescapable degenerative attractor. To mitigate this loop, generation frameworks often introduce \emph{repetition penalties}:
\begin{equation}
z'_{t,v} = \begin{cases}
z_{t,v} / \theta & \text{if } z_{t,v} > 0 \text{ and } v \in \mathbf{x}_{<t}, \\
z_{t,v} \cdot \theta & \text{if } z_{t,v} \le 0 \text{ and } v \in \mathbf{x}_{<t},
\end{cases}
\label{eq:repetition_penalty_formula}
\end{equation}
where $\theta > 1.0$ penalizes previously generated tokens.

\paragraph{Beam Search}
Beam search expands the greedy horizon by tracking the top $B$ most probable partial sequences (the \emph{beam width}) at each step. Let $\mathcal{B}_{t-1} = \{\mathbf{y}_1, \dots, \mathbf{y}_B\}$ denote the set of active hypotheses at step $t-1$. At step $t$, the algorithm evaluates the Cartesian product of all active beams and the entire vocabulary:
\begin{equation}
\mathcal{C}_t = \mathcal{B}_{t-1} \times \mathcal{V} = \{(\mathbf{y}_b, v) \mid \mathbf{y}_b \in \mathcal{B}_{t-1}, v \in \mathcal{V}\},
\label{eq:beam_candidate_set}
\end{equation}
scoring each candidate trajectory by its cumulative log-likelihood:
\begin{equation}
\text{Score}(\mathbf{y}_b \circ v) = \log P(\mathbf{y}_b \mid \mathbf{x}) + \log P(v \mid \mathbf{x}, \mathbf{y}_b).
\label{eq:beam_search_log_score}
\end{equation}
The set is then pruned back to the top $B$ candidates:
\begin{equation}
\mathcal{B}_t = \arg\max_{\mathcal{B} \subset \mathcal{C}_t, |\mathcal{B}|=B} \sum_{\mathbf{y} \in \mathcal{B}} \text{Score}(\mathbf{y}).
\label{eq:beam_search_prune}
\end{equation}

\caption{Beam search decoding with beam width $B=2$ (inspired by Slide~101). At each step, all $B$ active sequences are expanded across vocabulary candidates and pruned back to the $B$ sequences with highest cumulative probability.}
\label{fig:beam_search_trellis}
\end{figure}

Because cumulative probability monotonically decreases with sequence length ($\log P \le 0$), raw beam search exhibits a strong structural bias toward prematurely terminating with short sequences. To counter this, practitioners apply a length normalization penalty:
\begin{equation}
\mathcal{S}(\mathbf{y}) = \frac{\sum_{t=1}^T \log P(y_t \mid \mathbf{y}_{<t}, \mathbf{x})}{(5 + T)^\alpha / (5 + 1)^\alpha},
\label{eq:beam_length_penalty}
\end{equation}
where $\alpha \in [0.6, 1.0]$ scales length normalization.

While beam search is standard for deterministic, constrained sequence mapping (e.g., machine translation and abstractive summarization), it is poorly suited for open-ended generation: high probability beams converge on repetitive, bland text.


\subsection{Stochastic sampling: temperature scaling, Top-k, and Top-p}
\label{subsec:stochastic_sampling}

To generate natural, non-repetitive text, decoding must draw tokens stochastically from the predicted distribution: $\hat{x}_t \sim P(x_t \mid \mathbf{x}_{<t})$. However, unrestricted sampling introduces vulnerabilities that require calibrated truncation.

\paragraph{Pure Random Sampling and the Long Tail Risk}
Under pure multinomial sampling, the next token is sampled directly from the raw softmax distribution over all $|\mathcal{V}|$ tokens. While this guarantees non-deterministic outputs, it exposes generation to the \emph{long tail risk}.

Modern vocabularies contain tens of thousands of tokens ($|\mathcal{V}| \ge 32,000$). Even when individual probability values for implausible words are small (e.g., $P \approx 10^{-4}$), their cumulative probability mass across thousands of tail tokens is substantial. Inevitably, the random draw samples an incoherent or contextually inappropriate token from this distribution tail, permanently derailing subsequent generation.

This failure mode is shown in Slide~103. Under pure random sampling on the Sherlock Holmes prompt, the continuation rapidly devolves into syntactic disarray:
\begin{quote}
\texttt{"...It was alarmed me, as I had never heard of him before but last, yet I went to put something into his hand which I carried open and which I then pocketed into the drawer, so as not to be seen until soon afterwards. Then it was as though in a dream, and my amazement owled wild--it seems an impossibility..."}
\end{quote}

\paragraph{Temperature Scaling}
Temperature scaling modulates the entropy of the categorical distribution by dividing raw logits by a positive hyperparameter $T > 0$ prior to the softmax operator:
\begin{equation}
P_T(x_t = v \mid \mathbf{x}_{<t}) = \frac{\exp(z_{t,v} / T)}{\sum_{j=1}^{|\mathcal{V}|} \exp(z_{t,j} / T)}.
\label{eq:temperature_softmax}
\end{equation}

The mathematical behavior across different temperature regimes is bounded by two analytical limits:
\begin{itemize}
    \item \textbf{Limit $T \to 0^+$ (Argmax / Zero Entropy)}: Dividing logits by an infinitesimal value exaggerates differences between logits, collapsing the distribution to a Dirac delta centered at the mode:
    \begin{equation}
    \lim_{T \to 0^+} P_T(x_t = v \mid \mathbf{x}_{<t}) = \begin{cases}
    1 & \text{if } v = \arg\max_{j} z_{t,j}, \\
    0 & \text{otherwise},
    \end{cases}
    \label{eq:temperature_zero_limit}
    \end{equation}
    recovering deterministic greedy search.
    
    \item \textbf{Limit $T \to \infty$ (Uniform Distribution / Maximum Entropy)}: As $T$ approaches infinity, scaled logits converge to zero ($z_{t,v}/T \to 0$), flattening softmax into a discrete uniform distribution:
    \begin{equation}
    \lim_{T \to \infty} P_T(x_t = v \mid \mathbf{x}_{<t}) = \frac{1}{|\mathcal{V}|}, \quad \forall v \in \mathcal{V}.
    \label{eq:temperature_inf_limit}
    \end{equation}
\end{itemize}

\paragraph{Top-$k$ Sampling (Fixed Cardinality Truncation)}
Introduced by Fan et al.~\cite{fan2018}, Top-$k$ sampling addresses the long-tail vulnerability by restricting the sampling pool to the $k$ most probable tokens. Formally, tokens are sorted in descending order of probability:
\begin{equation}
P(x^{(1)} \mid \mathbf{x}_{<t}) \ge P(x^{(2)} \mid \mathbf{x}_{<t}) \ge \dots \ge P(x^{(|\mathcal{V}|)} \mid \mathbf{x}_{<t}).
\end{equation}
The sampling support is truncated to the subset $V^{(k)} = \{x^{(1)}, \dots, x^{(k)}\} \subset \mathcal{V}$, and probabilities are renormalized:
\begin{equation}
P_{\text{top-}k}(x_t = v \mid \mathbf{x}_{<t}) = \begin{cases}
\frac{P(x_t = v \mid \mathbf{x}_{<t})}{\sum_{j \in V^{(k)}} P(x_t = j \mid \mathbf{x}_{<t})} & \text{if } v \in V^{(k)}, \\
0 & \text{otherwise}.
\end{cases}
\label{eq:top_k_renormalization}
\end{equation}

Under Top-$k$ sampling with $k=50$ (Slide~105), the Sherlock Holmes continuation maintains syntactic structure and thematic tone without degenerative loops:
\begin{quote}
\texttt{"...'You will think, Doctor, that a man of my age would be so much of a menace to me, if I were to refuse a pass for him. I should rather get a few things away from him than any which might injure his reputation...'"}
\end{quote}

However, Top-$k$ suffers from a core structural flaw: \emph{fixed cardinality cannot adapt to contextual uncertainty}. In low-entropy contexts where the model is highly confident (e.g., \texttt{"The Eiffel Tower is in"} $\to$ \texttt{"Paris"} with $P=0.98$), a fixed $k=50$ forces the algorithm to sample among 49 implausible tokens. Conversely, in high-entropy contexts where hundreds of valid completions exist, $k=50$ truncates plausible continuations.

\paragraph{Top-$p$ / Nucleus Sampling (Adaptive Cumulative Mass Truncation)}
To eliminate the rigidity of fixed cardinality, Holtzman et al.~\cite{holtzman2020} introduced \emph{Nucleus} (Top-$p$) sampling. Instead of clipping at a fixed rank $k$, nucleus sampling defines an adaptive candidate set $V^{(p)} \subset \mathcal{V}$ containing the minimal set of tokens whose cumulative probability mass meets or exceeds a target threshold $p \in (0, 1]$:
\begin{equation}
\sum_{v \in V^{(p)}} P(x_t = v \mid \mathbf{x}_{<t}) \ge p.
\label{eq:nucleus_set_definition}
\end{equation}

Formally, letting tokens be sorted in descending probability order, the cutoff index $k^*$ is determined by:
\begin{equation}
k^* = \min \left\{ K \in \{1, \dots, |\mathcal{V}|\} : \sum_{i=1}^K P(x^{(i)} \mid \mathbf{x}_{<t}) \ge p \right\}.
\label{eq:nucleus_cutoff_index}
\end{equation}
The candidate pool is defined by $V^{(p)} = \{x^{(1)}, \dots, x^{(k^*)}\}$, and probabilities are renormalized over this dynamic set:
\begin{equation}
P_{\text{top-}p}(x_t = v \mid \mathbf{x}_{<t}) = \begin{cases}
\frac{P(x_t = v \mid \mathbf{x}_{<t})}{\sum_{j \in V^{(p)}} P(x_t = j \mid \mathbf{x}_{<t})} & \text{if } v \in V^{(p)}, \\
0 & \text{otherwise}.
\end{cases}
\label{eq:nucleus_renormalization}
\end{equation}

\end{quote}

In production language modeling systems, practitioners typically chain these mechanisms into a unified multi-stage decoding pipeline:
\begin{equation}
\mathbf{z} \xrightarrow{\quad \text{Repetition Penalty} \quad} \mathbf{z}' \xrightarrow{\quad \text{Temperature } T \quad} \mathbf{z}'' \xrightarrow{\quad \text{Top-}k \text{ Truncation} \quad} \mathbf{p}' \xrightarrow{\quad \text{Top-}p \text{ Cutoff} \quad} \hat{x}_t \sim \text{Categorical}(\mathbf{p}'').
\label{eq:decoding_pipeline_stages}
\end{equation}
First, repetition penalties adjust logits of previously emitted tokens. Second, temperature scaling calibrates entropy. Third, Top-$k$ filtering eliminates the outer tail. Fourth, Top-$p$ thresholding dynamically isolates the nucleus. Finally, the next token is sampled from the renormalized distribution.

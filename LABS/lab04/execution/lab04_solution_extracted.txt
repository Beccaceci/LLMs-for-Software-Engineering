     For causal language modeling, the target token sequence begins as a copy of the input IDs. Positions with
     attention mask zero are changed to -100, the ignore index used by the cross-entropy loss. GPT-2 shifts labels
     internally: the logit at position t is compared with the target token at position t + 1. For a batch of B rows
     and length T = 1024, the model emits logits with shape B × T × V and labels with shape B × T , where V is
     vocabulary size. Causal attention blocks access to future positions; the attention mask marks padding, while
     ignored labels exclude padding from loss. These masks solve different problems.
 1   # TODO: Add labels to the dataset
 2   def add_labels(samples):
 3       # NOTE: The labels, in causal modeling, should be the same as the input_ids

 5           [token if attended else -100 for token, attended in zip(ids, mask)]
 6           for ids, mask in zip(samples["input_ids"], samples["attention_mask"])
 7       ] # Ignore padding in the loss; GPT-2 shifts labels internally.
 8       return samples

     1.3 Padding analysis and matched training window
     The fixed-length baseline pads each example independently to 1,024 tokens. The dynamic-padding table groups
     examples logically in batches of six; it does not alter the example set. In training, the memory-compatible
     physical microbatch remains one example with six-step accumulation, so length grouping cannot change
     padding inside those one-example microbatches.
         The first full-epoch dynamic-padding pilot exhausted the MPS memory pool after 2,367.7 seconds. Its
     diagnostic is preserved in Appendix A. To obtain a matched completed comparison, both successful arms below
     start from the same public GPT-2 checkpoint in separate clean kernels and run twelve updates with evaluation
     disabled. The measured window is therefore intentionally short and does not estimate held-out quality.
     The padding extension recovers each real sequence length by summing its attention mask. Since the earlier
     tokenizer padded to 1,024, this step removes padded positions conceptually without retokenizing or changing
     the examples. It verifies the requested 1,000/500 split and that all measured lengths are positive and within the
     truncation limit.

     The dataset wrapper trims stored examples back to attended tokens. The collator then pads each physical batch
     either to the fixed maximum or just to the longest sequence in that batch. Labels are cloned from the padded

 1   # Build correctly masked causal-LM batches. Padding uses EOS as its token ID,
 2   # so the attention mask—not token identity—decides which labels become -100.
 3   class UnpaddedTokenDataset(Dataset):
 4       def __init__(self, encoded):
 5           self.rows = []
 6           for row in encoded:
 7               length = int(sum(row["attention_mask"]))
 8               self.rows.append({"input_ids": row["input_ids"][:length], "attention_mask": row["attention_mask"][:length]})
 9       def __len__(self):
10           return len(self.rows)
11       def __getitem__(self, index):
12           return self.rows[index]
13
14   class CausalPaddingCollator:
15       def __init__(self, tokenizer, mode):
16           self.tokenizer, self.mode = tokenizer, mode
17       def __call__(self, features):
18           batch = self.tokenizer.pad(
19               [{"input_ids": f["input_ids"], "attention_mask": f["attention_mask"]} for f in features],
20               padding="max_length" if self.mode == "fixed" else True,
21               max_length=MAX_LENGTH if self.mode == "fixed" else None,
22               return_tensors="pt",
23           )
24           labels = batch["input_ids"].clone()
25           labels[batch["attention_mask"] == 0] = -100
26           batch["labels"] = labels
27           return batch
